01

Önce kafanı netleştir: FE mi, BE mi?

"Yaptığım şey frontend mi backend mi?" sorusunun cevabı burada. Kod yazmadan önce bu üç şemayı içine sindir — geri kalan her şey bunun üstüne oturuyor.

En sade tanım: Frontend (FE) = kullanıcının gördüğü ve dokunduğu taraf — tarayıcıda çalışır (buton, sayfa, form). Backend (BE) = kullanıcının görmediği taraf — sunucuda çalışır (veri, mantık, güvenlik, veritabanı). Fullstack = ikisini de yapabilen kişi. Kaba kural: görüyorsan frontend, göremiyorsan backend.

02

Teknoloji seçimi (ve nedeni)

Tek dil felsefesi: JavaScript/TypeScript hem FE hem BE'de. Yeni başlayan için ikinci bir dil öğrenmemek = yarı yük. Ayrıca "fullstack" ilanlarının en büyük havuzu burada.

Dil
JavaScript → TypeScript

Webin dili. TS, tip güvenliği ekler — mülakatta beklenir. Python gördüğün için mantık tanıdık gelecek.

Frontend
HTML · CSS · React

Önce saf HTML/CSS, sonra React (+Vite). Piyasanın #1 arayüz kütüphanesi.

Backend
Node.js · Express

JS ile sunucu. Basit, öğrenmesi hızlı, iş ilanlarında yaygın.

Veritabanı
PostgreSQL · SQL

Endüstri standardı ilişkisel DB. Prisma (ORM) ile konuşursun. SQL her mülakatta çıkar.

Araçlar
Git · GitHub · VS Code

İlk günden. Terminal + versiyon kontrolü = mesleğin bel kemiği.

Deploy
Vercel · Railway

Ücretsiz katman. FE Vercel'e, BE+DB Railway'e. "Canlı link" = portföyün canı.

Embedded köprü
ESP32 · Arduino/MicroPython

~$8 kart, WiFi'li. Sensör okur, senin API'ne HTTP atar. Capstone'un donanım yarısı.

Realtime
WebSocket

Canlı veri akışı — sensör her ölçtüğünde pano anında güncellenir.

Not — esnek

Python'a yakınlığı belirleyici olursa backend'i FastAPI (Python) ile de kurabiliriz; embedded tarafı MicroPython zaten Python. Ama tek-dil avantajı için başlangıçta JS/TS öneriyorum. Bunu 4. haftada tekrar değerlendiririz — erken karar vermeye gerek yok.

08

Capstone: "Fiziksel dünya → canlı pano"

Bu proje planın kalbi. Öğrendiğin her şeyi tek yerde toplar ve embedded keyfini işe çevirir. Mülakatta 40 dakika konuşabileceğin tek şey.

Donanım yarısı

~$8'lik ESP32 kartı + bir DHT22 (sıcaklık/nem) sensör. MicroPython veya Arduino ile firmware: sensörü oku, WiFi'ye bağlan, her 10 saniyede senin API'ne bir ölçüm gönder. GPIO, seri port, firmware kavramlarını burada gerçekten öğrenirsin.

Yazılım yarısı

Node/Express API ölçümü alır, Postgres'e yazar, WebSocket ile açık panolara anında iter. React panosu canlı grafik çizer (son 24 saat, min/maks, uyarı eşiği). Auth ile korunur, Vercel + Railway'e deploy edilir. Tam zincir sende.

Mülakat hikayesi

"Bir sensörden gelen fiziksel veriyi, kendi yazdığım API üzerinden veritabanına kaydedip, WebSocket'le canlı bir React panosunda gösteren uçtan uca bir sistem kurdum." — Bu cümle seni "tutorial bitiren junior" havuzundan çıkarır. Donanım + fullstack birleşimi nadir; senin farkın bu.
